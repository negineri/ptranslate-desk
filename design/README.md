# デスクトップ画面のデザイン用HTML

[desktop-preview.html](desktop-preview.html)をブラウザで開いてください。
ロゴ・HTML・CSS・表示用JavaScriptを1つのファイルにまとめているため、このHTMLだけを渡せます。
サーバーの起動やアプリのインストールは不要です。

## 確認できる状態

上部の「状態」で切り替えます。

- 初回のモード選択
- サーバー設定
- モデル未取得・ダウンロード確認・ダウンロード中・取得エラー
- デバイス計測中・候補の表示・手動選択
- メモリ自動解放の設定
- モデル読み込み中・翻訳画面

「配色」でライト／ダーク、「幅」で1120px・960px・760px・全幅を選べます。
確認用ツールバーの下にアプリ本体を表示します。既定の確認枠は幅1120px、最小高さ760pxです。
ボタンで取得や計測を進める操作も再現していますが、通信・翻訳・モデル取得・設定保存は行いません。
表示する文章・デバイス・計測値はサンプルです。

## 編集・返却

HTML内の要素と`<style>`を直接編集し、保存後にブラウザを更新してください。
確認用ツールバーのCSSはコメントで区切っています。
変更後のHTMLを返却すれば、アプリ側のHTML・CSSへ反映できます。

元の画面は以下のファイルです。

- `desktop/local-view.mjs`：初回選択、モデル取得、デバイス・メモリ設定
- `desktop/settings-view.mjs`：ヘッダー、タブ、設定画面の共通スタイル
- `desktop/connection.mjs`：接続先設定
- `desktop/transport.mjs`：デスクトップ設定
- `desktop/translation-layout.mjs`：翻訳画面のデスクトップ向け操作配置
- `server/static/index.html`：翻訳画面と共通スタイル

開発者が作り直す場合は、リポジトリのルートで以下を実行します。
再生成するとHTMLへの直接編集は上書きされるため、デザイナーの編集済みファイルは別名で保管してください。

```powershell
node tools/export_desktop_design.mjs
```
