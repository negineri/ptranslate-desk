# PTranslate for Chrome プライバシーポリシー

公開者は negineri です。

PTranslate for Chromeは、利用者が翻訳を開始したタブのページ本文、または利用者が選択した文章を翻訳します。ページ翻訳中は、そのページ内で追加・変更された翻訳対象の文章も処理します。「中止」または「原文に戻す」で追従を停止できます。

サーバーモードでは、原文、翻訳言語、用語集、文脈として使う前の原文と訳などを利用者が設定したサーバーへ送ります。ブラウザーはその接続先への既存の認証Cookieをリクエストに含めることがあります。サーバーから返る利用者名は接続確認画面に表示します。公開者は翻訳サーバーを提供していません。翻訳データの受領者は利用者が指定した接続先の運用者です。サーバー側の処理、ログ、保持期間は、その接続先の運用者が管理します。

ローカルモードでは、翻訳対象のデータをこの端末上のPTranslate Deskに渡し、端末上で翻訳します。翻訳先として外部の翻訳サーバーに本文を送信しません。モデルの取得やアプリの更新時には、デスクトップアプリが配布元と通信します。

拡張はサーバーURL、翻訳言語、用語集などをブラウザーの拡張用ストレージに保存します。拡張内で原文や訳文を永続的な翻訳履歴として保存する機能はありません。保存した設定は拡張の設定画面から変更でき、拡張を削除するとブラウザー内の拡張用ストレージも削除されます。

問い合わせ先は、[PTranslateのGitHub Issues](https://github.com/negineri/ptranslate-desk/issues)です。公開の投稿には、原文や認証情報などの個人情報を含めないでください。
