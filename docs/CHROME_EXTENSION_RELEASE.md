# Chrome拡張の導入と更新

PTranslate for Chromeは、PTranslateサーバーを使って選択文やページ全体を訳す拡張です。
Chrome 120以降、EdgeなどのChromium系ブラウザーに対応します。
ローカル翻訳エンジンは拡張に含まれず、利用できるPTranslateサーバーとログインが必要です。

## 配布ファイル

[GitHub Releases](https://github.com/negineri/ptranslate-desk/releases)のAssetsから、
`PTranslate.Chrome_<version>.zip` と、必要に応じて `.zip.sha256` を取得します。
ZIPが付いているReleaseを選んでください。Chromeウェブストアには掲載していません。
ZIPは手動導入用であり、ダウンロードするだけではインストールされません。

SHA-256を照合する場合、両方のファイルを同じフォルダーへ置き、端末で次を実行します。
ファイル名は取得した版へ読み替えてください。

```sh
# macOS
shasum -a 256 -c PTranslate.Chrome_1.2.3.zip.sha256
# Linux
sha256sum -c PTranslate.Chrome_1.2.3.zip.sha256
```

WindowsのPowerShellでは `Get-FileHash .\PTranslate.Chrome_1.2.3.zip -Algorithm SHA256` の結果と、
`.sha256` ファイルに書かれた値を比較します。SHA-256はファイルの一致を調べるもので、コード署名ではありません。

## 初回導入

1. ZIPを、今後も置いておける専用フォルダーへ展開します。展開したフォルダーの直下に `manifest.json` があることを確認します。
2. Chromeの `chrome://extensions/`、Edgeの `edge://extensions/` を開き、デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から、`manifest.json` のあるフォルダーを選びます。
4. 拡張の設定でサーバーURLを入力し、「保存して接続を確かめる」を押します。
   指定したサーバーへの接続許可を求められたら確認します。
5. 同じブラウザーでそのサーバーのWeb版へログインします。拡張はその認証Cookieを利用します。
6. ページで文を選んで右クリック→「PTranslate で翻訳」、または「PTranslate でこのページを翻訳」を使います。

読み込んだフォルダーは削除・移動しないでください。組織の管理ポリシーで手動導入が制限されている場合は、管理者に確認してください。

## 手動更新

自動更新には対応していません。同じフォルダーを使って更新します。

1. 新しいZIPを取得して、必要に応じてSHA-256を照合します。
2. 翻訳バーの「中止」で動作を止め、最初に読み込んだ専用フォルダーの中身を新しい版のファイルに置き換えます。
3. 拡張管理画面でPTranslateの再読み込みボタンを押します。
4. 翻訳対象のタブも再読み込みし、拡張の表示バージョンを確認します。

同じフォルダーを使い、拡張を削除せず再読み込みすれば、同じ拡張IDで設定を引き継げます。
拡張の削除や別フォルダーへの導入では設定を失う場合があるため、サーバーURLや用語集を控えてください。
プレリリースは数値バージョンが正式版と同じ場合があります。表示名の `-beta.1` などで区別してください。

## 送信する文章と権限

- 選択文の翻訳では選択した文章、ページ翻訳では対象となったページの文章を、設定したサーバーへ送ります。
- ページ翻訳の開始後は、チャンネル切り替え・新着・open Shadow DOM内の文章も対象です。
  「中止」「原文に戻す」で自動追従を停止します。バーを閉じるだけでは停止しません。
- `activeTab` と `scripting` は利用者が起動したタブの文章取得・訳の表示、`contextMenus` は右クリックメニュー、
  `storage` は設定の保存に使います。サーバーへのホスト権限は設定保存時に指定先だけ求めます。
- 設定と用語集をブラウザーに保存します。原文と訳はディスクへ保存せず、翻訳サーバー以外へ送信しません。
  サーバーの運用者とデータの取り扱いを確認したうえで利用してください。

コード、入力・編集欄、翻訳禁止指定のある文章などは除外します。iframe、closed Shadow DOM、画像内の文字は対象外です。
詳しい動作と制限は[Chrome拡張の説明](../chrome-extension/README.md)を参照してください。
