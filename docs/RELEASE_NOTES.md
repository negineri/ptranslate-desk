v0.4.0-beta.2では、Chrome拡張とデスクトップのローカル翻訳を連携し、ページ翻訳とGPUの並列数計測を改善しました。

## Chrome拡張

- Windowsではデスクトップのローカル推論でページ・選択文を翻訳できます。設定の「接続」からChrome連携を登録できます。
- サーバーモードも引き続き利用できます。接続先が通知する同時実行上限を使い、ローカルではデスクトップと実行枠を共有します。
- 表示領域を優先し、スクロールした場所を先に訳します。画面外の要素や非表示要素の判定を改善しました。
- 接続済みなら拡張アイコンをクリックするとページ翻訳を開始します。設定は右クリックから開けます。初回導入時には設定画面を開きます。
- 翻訳バーをコンパクトな2段にし、文言とボタン配置を整理しました。翻訳先の初期値は日本語です。
- 設定の接続操作を統合し、拡張のテキスト入力による翻訳画面を削除しました。入力翻訳はWeb版・デスクトップ版を利用してください。
- 中止と切断を推論エンジンへ伝え、終了するまで実行枠を保持するようにしました。

Assetsの `PTranslate.Chrome_` で始まるZIPを展開し、ChromeまたはEdgeの拡張管理画面で
「パッケージ化されていない拡張機能を読み込む」から導入してください。既存の拡張も手動更新が必要です。
導入・更新手順: https://github.com/negineri/ptranslate-desk/blob/main/docs/CHROME_EXTENSION_RELEASE.md
拡張のストア配布と自動更新は未対応です。ローカル連携にはデスクトップの起動が必要です。
macOSではデスクトップ単体のローカル翻訳と拡張のサーバーモードを利用できます。拡張のローカル連携はWindows向けです。

## デスクトップのローカル翻訳

- GPUを計測し、推奨デバイスと並列数を設定欄へ自動入力します。数値への補正は行いません。「保存して再起動」で反映します。
- 並列数は1〜64件の数値で指定します。自動・手動の切り替えと長文追加計測ボタンを削除しました。
- 並列数の計測は、短い項目・見出し・段落を混ぜた同じ192件を各候補で処理します。直前の訳を文脈として使い、通常の翻訳とストリーミング・キャッシュ設定をそろえました。CPUの並列数は計測しません。
- 計測済みの状態で翻訳モードを切り替えても再計測しません。必要に応じて「計測して候補を確認」からやり直せます。
- 手動のモデル解放ボタンを削除し、処理中・待機中の要求を考慮して未使用時に自動解放します。
- モデル情報のリンクを外部ブラウザーで開くようにし、並列数入力の見た目と余白を修正しました。

計測値は全サイト共通の最適値を保証しません。Chrome内の通信・描画時間は計測に含みません。
macOSでの実モデル翻訳は実機未確認です。

## Windows

Windows 10 / 11（x64）向けのNSISインストーラーを追加しました。
Assetsの `_x64-setup.exe` で終わるファイルをダウンロードしてインストールしてください。

**Windowsコード署名は未対応です。SmartScreenの警告が表示される場合があります。**
このリポジトリのReleaseから取得したファイルであることと、バージョンを確認してください。
組織の端末で実行が制限される場合は管理者へ確認してください。

メインウィンドウでの翻訳、ブラウザでのログイン、通知領域への常駐、Ctrl+Cを0.5秒以内に2回押す選択文の翻訳に対応します。
設定でCtrl+Shift+Tなどにも切り替えられます。メインウィンドウを閉じても常駐し、トレイの「終了」で終了します。
ログイン情報はWindowsの資格情報マネージャーへ保存します。

自動更新は利用者が承認した後に適用します。更新ファイルはコード署名とは別のTauri更新署名で検証します。
インストール時にアプリを終了し、完了後に起動し直します。

クリーンな端末での導入・削除、WebView2未導入環境、Windows更新インストーラーの適用と
再起動・設定維持、クリップボード復元、再起動後のログイン維持は、実機ではまだ確認していません。

## macOS

Tauri更新署名鍵を切り替えています。**v0.2.3以前からの自動更新はできません。今回だけDMGをダウンロードして手動インストールしてください。**
この版以降は新しい更新署名鍵で自動更新できます。macOSコード署名証明書は変更していません。

CIのビルドと署名を分離し、秘密鍵を署名専用ジョブ・ステップでだけ使用します。
更新アーカイブとバージョンの署名を、アプリ内の公開鍵で検証してから公開します。

macOS 13以降向けのuniversal版です。Apple SiliconとIntelの両方で使えます。

dmgを開き、PTranslate Deskをアプリケーションフォルダに入れてください。

AppleのDeveloper ID署名・公証は未対応です。起動がブロックされた場合は、
「システム設定 → プライバシーとセキュリティ → このまま開く」を選んでください。

アプリは更新をまたいで同じ自己署名証明書を使います。
旧版からこの署名へ切り替える最初の1回は、アクセシビリティの許可を再登録してください。
更新用ファイルはTauriの更新署名で検証します。
