Tauri更新署名鍵を切り替えました。**v0.2.3以前からの自動更新はできません。今回だけDMGをダウンロードして手動インストールしてください。**
この版以降は新しい更新署名鍵で自動更新できます。macOSコード署名証明書は変更していません。

CIのビルドと署名を分離し、秘密鍵を署名専用ジョブ・ステップでだけ使用します。
更新アーカイブとバージョンの署名を、アプリ内の公開鍵で検証してから公開します。

macOS 13以降向けのuniversal版です。Apple SiliconとIntelの両方で使えます。

dmgを開き、PTranslate Deskをアプリケーションフォルダに入れてください。

AppleのDeveloper ID署名・公証は未対応です。起動がブロックされた場合は、
「システム設定 → プライバシーとセキュリティ → このまま開く」を選んでください。

アプリは更新をまたいで同じ自己署名証明書を使います。
旧版からこの署名へ切り替える最初の1回は、アクセシビリティの許可を再登録してください。
更新用ファイルはTauriの更新署名で検証します。
