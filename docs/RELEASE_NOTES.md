v0.4.1では、Chrome拡張のページ翻訳を高速化しました。

- 画面に表示されている範囲を優先し、画面内と画面外のそれぞれで長文を先に訳します。
- 日本語へのページ翻訳では、対象となる画面外の短文を4件ずつまとめて送ります。訳の番号を照合できなかった場合は、そのグループを個別に訳し直します。
- デスクトップのローカル翻訳を4並列で使った計測では、比較した9ページのうち8ページで全件完了が24〜39%短縮しました。

Chrome拡張を更新するには、Assetsの `PTranslate.Chrome_` で始まるZIPを使います。[Chrome拡張の導入・更新手順](https://github.com/negineri/ptranslate-desk/blob/main/docs/CHROME_EXTENSION_RELEASE.md)

## v0.4.0の主な変更

v0.4.0は、初期設定ウィザードと翻訳先の切り替えを追加し、macOSでもChrome拡張からローカル翻訳できるようにした正式版です。

## デスクトップ

- 初回起動時のウィザードで、翻訳先、モデルのダウンロード、サーバーへのログイン、ショートカットを設定できます。設定画面からもウィザードを開けます。
- メイン画面の右上にあるボタンでサーバー翻訳とローカル翻訳を切り替えます。選択した翻訳先は次の起動時にも引き継がれます。
- 設定ではサーバー翻訳とローカル翻訳を別々に管理できます。接続先の変更はアプリの再起動なしで適用できます。
- ローカル翻訳の推奨並列数は、約1,500字の英文を使って決めます。候補ごとの処理速度と見込みメモリを表示し、空きメモリが不足する候補は計測を省略します。

## Chrome拡張

- Windows x64とmacOS 13.3以降のGoogle Chromeで、デスクトップアプリのローカルモデルを使ってページや選択文を翻訳できます。
- 選択文とページ翻訳のポップアップに「PLaMo 3 Translate」の表記を追加しました。

Assetsの `PTranslate.Chrome_` で始まるZIPを展開し、Chromeの拡張管理画面で「パッケージ化されていない拡張機能を読み込む」から導入してください。既存の拡張も手動更新が必要です。
[Chrome拡張の導入・更新手順](https://github.com/negineri/ptranslate-desk/blob/main/docs/CHROME_EXTENSION_RELEASE.md)

## Windows

Windows 10 / 11（x64）向けのNSISインストーラーを追加しました。
Assetsの `_x64-setup.exe` で終わるファイルをダウンロードしてインストールしてください。

**Windowsコード署名は未対応です。SmartScreenの警告が表示される場合があります。**
このリポジトリのReleaseから取得したファイルであることと、バージョンを確認してください。
組織の端末で実行が制限される場合は管理者へ確認してください。

メインウィンドウでの翻訳、ブラウザでのログイン、通知領域への常駐、Ctrl+Cを0.5秒以内に2回押す選択文の翻訳に対応します。
設定でCtrl+Shift+Tなどにも切り替えられます。メインウィンドウを閉じても常駐し、トレイの「終了」で終了します。
ログイン情報はWindowsの資格情報マネージャーへ保存します。

自動更新は利用者が承認した後に適用します。更新ファイルはコード署名とは別のTauri更新署名で検証します。
インストール時にアプリを終了し、完了後に起動し直します。

クリーンな端末での導入・削除、WebView2未導入環境、Windows更新インストーラーの適用と
再起動・設定維持、クリップボード復元、再起動後のログイン維持は、実機ではまだ確認していません。

## macOS

Tauri更新署名鍵を切り替えています。**v0.2.3以前からの自動更新はできません。今回だけDMGをダウンロードして手動インストールしてください。**
この版以降は新しい更新署名鍵で自動更新できます。macOSコード署名証明書は変更していません。

CIのビルドと署名を分離し、秘密鍵を署名専用ジョブ・ステップでだけ使用します。
更新アーカイブとバージョンの署名を、アプリ内の公開鍵で検証してから公開します。

macOS 13以降向けのuniversal版です。Apple SiliconとIntelの両方で使えます。

dmgを開き、PTranslate Deskをアプリケーションフォルダに入れてください。

AppleのDeveloper ID署名・公証は未対応です。起動がブロックされた場合は、
「システム設定 → プライバシーとセキュリティ → このまま開く」を選んでください。

アプリは更新をまたいで同じ自己署名証明書を使います。
旧版からこの署名へ切り替える最初の1回は、アクセシビリティの許可を再登録してください。
更新用ファイルはTauriの更新署名で検証します。
