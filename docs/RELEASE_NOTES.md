このReleaseでは、Chrome拡張のZIP配布と、Windows・macOSのローカル翻訳モードを追加します。

## Chrome拡張

Assetsの `PTranslate.Chrome_` で始まるZIPを展開し、ChromeまたはEdgeの拡張管理画面で
「パッケージ化されていない拡張機能を読み込む」から導入してください。
導入と手動更新の手順: https://github.com/negineri/ptranslate-desk/blob/main/docs/CHROME_EXTENSION_RELEASE.md

- 選択した文章、ページ全体の翻訳に対応します。表示中の本文を優先し、最大2か所を並列に訳します。
- チャンネル切り替えや新着文章、open Shadow DOM内の文章にも追従します。
  「中止」「原文に戻す」で停止します。バーを閉じるだけでは追従は止まりません。
- 利用にはPTranslateサーバーと、同じブラウザーでのWeb版へのログインが必要です。
  拡張単体のローカル翻訳、ストアからの導入、自動更新には対応していません。
- 任意で `.zip.sha256` を使ってファイルの一致を確認できます。Chrome拡張へのコード署名は付けていません。

## デスクトップのローカル翻訳

- 初回設定で「このPCで翻訳」と「サーバーで翻訳」を選べます。
- Windows x64はVulkan GPU・CPU、macOS 13.3以降のApple Silicon・IntelはMetal GPU・CPUに対応します。
- モデルと推論エンジンは取得前に確認を求め、取得後にSHA-256を検証します。
  デバイスの計測・手動選択、起動時の読み込み、未使用時のメモリ解放を設定できます。
- macOSの実モデル翻訳は実機未確認です。macOSでアプリを強制終了した場合の推論プロセスの連動終了は未対応です。

## Pocket IDとかんたん構築

- **Pocket IDでログインできるようにしました。** discoveryに `revocation_endpoint` が無いIdPでも、
  デスクトップ版がログインできます。その場合のログアウトは端末から認証情報を消すだけで、
  サーバー側のrefresh tokenは有効期限まで残ります
- **サーバー:** `TR_USERINFO_URL` を追加しました。access tokenにユーザー名が入らないIdP（Pocket ID）でも、
  デスクトップ版からの要求の利用者名をIdPのuserinfoから引きます。設定しなければ従来と同じです
- **かんたん構築:** IdPもリバースプロキシも無い環境向けに、Tailscale + Pocket IDで1台に立てる
  Docker Composeの構成と手順（docs/SELF_HOSTING_COMPOSE.md）を追加しました。外に開けるポートは不要です
- 翻訳エンジンの速さを測る `tools/bench.py` と、訳の繰り返しと揺れの調査記録（docs/REPEAT_INVESTIGATION.md）を追加しました

## Windows

Windows 10 / 11（x64）向けのNSISインストーラーを追加しました。
Assetsの `_x64-setup.exe` で終わるファイルをダウンロードしてインストールしてください。

**Windowsコード署名は未対応です。SmartScreenの警告が表示される場合があります。**
このリポジトリのReleaseから取得したファイルであることと、バージョンを確認してください。
組織の端末で実行が制限される場合は管理者へ確認してください。

メインウィンドウでの翻訳、ブラウザでのログイン、通知領域への常駐、Ctrl+Cを0.5秒以内に2回押す選択文の翻訳に対応します。
設定でCtrl+Shift+Tなどにも切り替えられます。メインウィンドウを閉じても常駐し、トレイの「終了」で終了します。
ログイン情報はWindowsの資格情報マネージャーへ保存します。

自動更新は利用者が承認した後に適用します。更新ファイルはコード署名とは別のTauri更新署名で検証します。
インストール時にアプリを終了し、完了後に起動し直します。

クリーンな端末での導入・削除、WebView2未導入環境、Windows更新インストーラーの適用と
再起動・設定維持、クリップボード復元、再起動後のログイン維持は、実機ではまだ確認していません。

## macOS

Tauri更新署名鍵を切り替えています。**v0.2.3以前からの自動更新はできません。今回だけDMGをダウンロードして手動インストールしてください。**
この版以降は新しい更新署名鍵で自動更新できます。macOSコード署名証明書は変更していません。

CIのビルドと署名を分離し、秘密鍵を署名専用ジョブ・ステップでだけ使用します。
更新アーカイブとバージョンの署名を、アプリ内の公開鍵で検証してから公開します。

macOS 13以降向けのuniversal版です。Apple SiliconとIntelの両方で使えます。

dmgを開き、PTranslate Deskをアプリケーションフォルダに入れてください。

AppleのDeveloper ID署名・公証は未対応です。起動がブロックされた場合は、
「システム設定 → プライバシーとセキュリティ → このまま開く」を選んでください。

アプリは更新をまたいで同じ自己署名証明書を使います。
旧版からこの署名へ切り替える最初の1回は、アクセシビリティの許可を再登録してください。
更新用ファイルはTauriの更新署名で検証します。
